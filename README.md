# 뚱냥이의 시장경제 퀴즈

초등 사회 6-2 시장경제와 국가 간 거래. 90초 동안 최대 20문제, 정답당 10점과 0.25 kg. 문제 은행은 38 + 32 + 30문항입니다.

- `npm test`로 문항 구조, 채점, 시간 제한, 서버 순위 저장을 검증합니다. Node.js 22.13 이상이 필요합니다.
- `npm run build`는 Cloudflare Worker 형식으로 빌드합니다. 독립 배포 시 `project_id`가 포함된 `.openai/hosting.json`을 준비하고 D1을 `DB`로 연결한 뒤 `drizzle/0000_game.sql`을 적용합니다. 이 저장소에는 배포 대상의 프로젝트 설정이 포함되지 않습니다.
- 출처는 제공된 PDF 4종입니다. 시장경제 문항은 《소단원 1, 2 한장정리》, 경제성장 문항은 이 자료와 《사회 공책정리 6-2-2》 및 《알짜정리학습지 2단원 (2)》, 무역 문항은 《사회 공책정리 6-2-3》에 근거합니다.
